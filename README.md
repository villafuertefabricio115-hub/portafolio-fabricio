## ✨ Características Principales

* **🎨 Diseño Moderno & Cyberpunk/Dark:** Interfaz oscura altamente estilizada con estética tecnológica.
* **📱 100% Responsivo:** Adaptado perfectamente a móviles, tablets y monitores de escritorio.
* **🚀 Rendimiento Optimizado:** Construido con Vite para tiempos de carga ultrarrápidos y animación fluida.
* **📩 Formulario de Contacto Real:** Integrado con la API de Web3Forms para recibir mensajes directamente en Gmail.
* **🧩 Componentes Modulares:** Código limpio, mantenible y reutilizable escrito en React.

---

## 🛠️ Stack Tecnológico

| Tecnología | Descripción |
| :--- | :--- |
| **React 19** | Biblioteca para la construcción de interfaces de usuario |
| **Vite** | Bundler y entorno de desarrollo ultrarrápido |
| **Tailwind CSS v4** | Framework de CSS utilitario para diseño moderno |
| **React Icons** | Iconografía vectorial e interactiva |
| **Web3Forms** | Backend serverless para envío de formularios |
| **Vercel** | Hosting cloud con despliegue continuo (CI/CD) |

## 📁 Estructura del Proyecto

```text
mi-portafolio/
├── public/              # Archivos estáticos y favicon

│   ├── main.jsx         # Punto de entrada de React
│   └── index.css        # Estilos globales y configuración de Tailwind CSS
├── index.html           # Plantilla HTML principal
├── vite.config.js       # Configuración del empaquetador Vite
└── package.json         # Dependencias y scripts
