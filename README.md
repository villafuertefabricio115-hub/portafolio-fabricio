# Fabricio Villafuerte — Portafolio Personal

Portafolio web personal desarrollado con React y Vite para presentar mi perfil profesional, proyectos y formas de contacto de manera moderna y visual.

## ✨ Características

- Sección de inicio con presentación personal
- Información sobre mi experiencia y enfoque profesional
- Vista de proyectos destacados
- Sección de habilidades y tecnologías
- Formulario de contacto integrado con Web3Forms

## 🛠️ Tecnologías utilizadas

- React 19
- Vite
- Tailwind CSS v4
- React Icons

## ▶️ Requisitos

- Node.js 18 o superior
- npm

## ⚙️ Instalación

```bash
npm install
npm run dev
```

## 🧪 Scripts disponibles

```bash
npm run dev
npm run build
npm run preview
```

## 🔐 Variables de entorno

Para que el formulario de contacto funcione correctamente, crea un archivo llamado `.env.local` en la raíz del proyecto con la siguiente variable:

```env
VITE_WEB3FORMS_ACCESS_KEY=tu_access_key
```

## 🚀 Despliegue

El proyecto puede desplegarse fácilmente en plataformas como Vercel, Netlify o GitHub Pages.

## 📬 Contacto

Si quieres colaborar, hablar de proyectos o simplemente conectar, puedes hacerlo a través del formulario de contacto del portafolio o por mis redes profesionales.

## 📁 Estructura del proyecto

- `src/components` — componentes principales del portafolio
- `src/img` — recursos visuales
- `public` — archivos estáticos
